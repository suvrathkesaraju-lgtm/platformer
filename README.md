# platformer
Its a platformer i made and its the first time i tried. i honestly had no idea for a concept and just went with the flow. i found textures i liked and chose to use those as the textures for the game and just built something very bare. honestly as someone who never touched a game engine before i am super overwhelmed and think the product is very underwhelming. Anyways here are the controls


CONTROLS:


D - Move right


A - Move Left


Space - Jump


HOW TO RUN:


Install the zip file from the releases and extract it then go inside and run the binary that was amde f0or your OS(.x86_64 for linux and .exe for windows).
